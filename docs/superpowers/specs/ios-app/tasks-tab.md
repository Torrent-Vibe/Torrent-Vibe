# 任务 Tab

状态：已确认 · IOS-E10 已完成 · 更新：2026-08-18 · 任务：IOS-D02、IOS-E05、IOS-E10

返回 [设计总览](../2026-08-17-ios-app-design.md)。

## 页面职责

任务根页面需要立即回答：

1. 当前观察哪台服务器？
2. 哪些任务正在传输或需要处理？
3. 当前可以执行什么安全操作？

## 页面结构


根页面是列表工作区，不使用仪表盘卡片矩阵。

## 导航区

- Large Title：`任务`。
- Large Subtitle：当前服务器名称、健康状态和展开标识。
- 点击服务器上下文打开已有服务器菜单，并提供“管理服务器”入口。
- 右上主操作为添加；次级菜单包含刷新、选择模式和低频列表操作。
- Tab Bar 随主列表向下滚动收起，向上滚动重新展开。

## 全局传输 Accessory

- 使用 iOS 26 Tab Bar Bottom Accessory。
- 仅在存在活动传输或错误时出现。
- 展示当前服务器、上下行速度和活动或错误数量。
- 点击后回到任务 Tab，不在 accessory 内放置暂停全部等操作。
- 任务页面不再重复绘制速度概览卡片。

## 搜索与筛选

- 搜索位于顶部，按需展开；不使用全局 Search Tab 或底部搜索栏。
- 输入时即时过滤当前服务器任务。
- 默认筛选为“全部”，并按服务器记忆最后一次筛选。
- 逻辑范围包括：全部、下载中、做种、已完成、已暂停、错误。
- 范围较少时使用系统 scope control；空间不足时使用 Filter Menu，不使用装饰性横向 pill 列表。
- 文本搜索在当前状态范围内执行。

## Torrent 行

每行只承载扫描所需信息：

- 最多两行名称。
- 进度和主要状态。
- 总大小。
- 当前有效的下载或上传速度。
- ETA、完成状态或错误提示。

| 交互         | 行为                                            |
| ------------ | ----------------------------------------------- |
| 点击         | Push Torrent 详情                               |
| 前导侧滑     | 根据当前状态暂停或继续                          |
| 尾随侧滑     | 进入仍需确认的删除操作                          |
| Context Menu | 暂停/继续、强制开始、重新校验、分类、标签、删除 |
| 编辑模式     | 多选并显示批量操作 Toolbar                      |

列表行不常驻操作按钮组。

## Torrent 详情

详情采用纵向摘要和子页面，不使用桌面式多 Tab Inspector。

1. 状态、进度、速度、ETA、分享率和大小。
2. 主操作：暂停或继续；其余操作进入 More Menu。
3. 保存路径、分类、标签、哈希和时间信息。
4. 文件、Tracker、Peer 和速度限制作为 Push 子页面。

删除必须明确区分：

- 移除任务并保留已下载文件。
- 移除任务并删除已下载文件。

## 添加 Torrent

添加流程由 UIKit-owned sheet 承载，统一接收：

1. Magnet 或 HTTP URL。
2. 系统文件选择器或 Share Extension 提供的 Torrent 文件。
3. 剪贴板中检测到的有效 Magnet 建议。
4. Discover 预填充的导入内容。

首屏只显示来源、目标服务器和必要目标信息；高级 qBittorrent 选项按需展开。最终按钮必须包含目标服务器，例如“添加到家庭 NAS”。

## 根状态

| 状态         | 表现                                       |
| ------------ | ------------------------------------------ |
| 无服务器     | 说明前置条件，并跳转设置中的添加服务器流程 |
| 连接中       | 保留页面结构，显示内联进度                 |
| 已连接但为空 | 以添加 Torrent 为主操作                    |
| 离线但有缓存 | 保留缓存任务，显示过期时间、诊断和重试     |
| 离线且无缓存 | 显示连接错误、重试和管理服务器             |
| 刷新中       | 保持现有列表稳定，不使用阻塞式整页 Spinner |

## 功能阶段

| 阶段         | 功能                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| 首个纵向闭环 | 连接、列表、刷新、搜索、筛选、暂停/继续、添加 Magnet、基础详情         |
| 第二阶段     | 文件导入、删除文件选择、分类、标签、限速、多选                         |
| 后续         | 文件、Tracker、Peer、顺序下载、Share Extension、后台状态、系统快捷指令 |

## 实现状态

- 已使用原生 qBittorrent Web API 完成登录、任务列表与全局传输速率刷新。
- 密码只写入 Keychain；服务器元数据继续保存在本地偏好设置中。
- 已验证覆盖安装、进程重启后的凭据恢复与自动刷新；服务器地址和凭据不进入文档。

### IOS-E06 共享导入 Sheet

- 任务页 `+` 可输入 Magnet 或 HTTP(S) Torrent URL；Discover 单集以只读来源预填同一 Sheet。
- 目标默认当前服务器，但提交前允许切换；最终按钮明确显示“添加到〈服务器〉”。
- 本批不展示保存路径、分类或标签；失败时保留 Sheet 与输入，成功后关闭并刷新当前服务器。

### IOS-E10 任务管理纵向闭环

- 使用系统 Menu 按状态筛选当前服务器任务，并在服务器间分别记忆筛选范围。
- 点击任务行由 UIKit Push 基础详情；详情展示传输、保存位置与标识信息。
- 详情主操作与列表前导侧滑均提供暂停或继续；真实接口接入 qBittorrent，验收使用 Demo Repository。
