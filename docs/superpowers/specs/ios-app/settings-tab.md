## 页面职责

设置负责服务器、凭据、Helper、Discover Provider、应用偏好和诊断。只收纳全局且低频的配置；搜索筛选、导入选项等任务级控制留在对应页面。

## 页面地图

```text
设置根页面
├── 服务器列表
│   ├── 添加 / 编辑服务器 Sheet
│   └── 服务器详情
│       ├── qBittorrent 连接
│       └── Helper 配对与配置
├── 内容来源
│   ├── Mikan
│   └── M-Team
├── 外观与刷新

├── 系统指令
├── 诊断
└── 关于
```

## 设置根页面提案

使用 Large Title `设置` 和系统 Inset Grouped List，不增加搜索框或自定义卡片。

| 分组 | 行         | 次级信息                   |
| ---- | ---------- | -------------------------- |
| 连接 | 服务器     | 当前服务器、数量和健康状态 |
| 发现 | 内容来源   | 已启用的 Provider          |
| 应用 | 外观       | 跟随系统、浅色或深色       |
| 应用 | 任务刷新   | 仅前台轮询间隔             |
| 应用 | 后台与通知 | 系统权限、调度和立即检查   |
| 应用 | 系统指令   | 三个 App Intents           |
| 支持 | 诊断       | 当前异常数量或“正常”       |
| 支持 | 关于       | 版本号                     |

- 导航行使用 Disclosure Indicator；简单 Picker 可在子页面保存后立即生效。
- 根页面不承担服务器切换，服务器行点击只进入管理层级。
- 外观默认跟随系统；不复制系统级辅助功能开关。
- iPad 常规宽度可将同一层级适配为列表与详情双栏，不新增信息架构。

## 服务器列表与详情

- 列表行显示名称、地址、连接状态及当前服务器标记；右上角 `+` 打开添加 Sheet。
- 点击服务器 Push 详情；设为当前服务器是详情页中的明确动作，不绑定在行点击上。
- 添加与编辑字段包括名称、WebUI 地址、用户名和密码；密码只进入 Keychain。
- 允许保存暂时离线的服务器，但必须保留测试连接结果和明确警告。
- 删除放在详情页底部的破坏性分组。删除当前服务器前必须选择替代项，或确认进入无服务器状态。

服务器详情按以下顺序组织：状态摘要、qBittorrent 连接、Helper、诊断动作、删除服务器。qBittorrent 的下载、连接、速度和高级偏好不在 iOS 首版复制。

## Helper

Helper 归属于服务器，不作为独立全局账户。

多客户端凭据、订阅真相源与解绑语义见 [Helper 集成边界](helper-integration.md)。在该契约确认前，不实现会清空远端状态的 iOS 解绑动作。

- 未配对：依次提供同主机探测、Bonjour 局域网发现和手动 URL。
- 已配对：显示地址、版本、待处理任务和最近同步状态。
- 配置页承载媒体库根目录、分类、qBittorrent 连接、代理和轮询间隔。
- 解绑必须说明本地绑定、Helper 副本和现有 Torrent 各自的保留行为。
- 局域网权限仅在首次发现 Helper 时请求，不在 App 启动时请求。

## 内容来源

- Mikan：启用状态与 Base URL；解析器固定随 App 发布，不提供远程脚本入口。
- M-Team：启用状态、API Base URL、模式、分页大小和 API Key；API Key 存入 Keychain。
- 保存前提供连接测试；禁用 Provider 后从发现根页面菜单隐藏，但保留配置。

### IOS-E17 内容来源连接测试

- Mikan 与 M-Team 各自提供独立测试、独立结果和明确保存动作；测试不会写入偏好或 Keychain。
- Mikan 测试对当前草稿 Base URL 发起只读根页面请求，验证 HTTP 成功状态与非空 UTF-8 页面。
- M-Team 测试使用当前草稿配置调用既有搜索契约的第一页，不调用详情、下载链接或导入动作。
- 字段变化会使旧测试结果失效，避免把上一份配置的成功状态显示为当前结果。
- `-ui-demo` 使用确定性测试服务，仅用于 Simulator 视觉与交互验收；真实请求契约由行为测试覆盖。

### IOS-E19 后台状态与下载完成通知

- 使用 `BGAppRefreshTask` 请求系统后台刷新；iOS 决定实际执行时间，App 不承诺固定轮询间隔。
- 首次检查只建立已完成任务基线，后续仅通知新完成项目；持久记录不包含服务器凭据。
- 下载完成使用本地通知，用户在设置中显式启用时才请求系统权限；不使用远程推送，也不新增 Push entitlement。
- “立即检查”复用同一检测逻辑并显示可见结果；后台处理只读取状态，不启动、暂停或删除任务。

### IOS-E20 系统指令

- App Shortcuts 注册“打开任务”“刷新任务”和“添加 Magnet”三个 App Intents。
- 前两项通过 UIKit 深链选择任务 Tab；刷新动作同时刷新当前服务器。
- Magnet 参数先验证，再进入既有导入确认页；系统指令不会自动提交下载。
- 设置页列出当前系统指令，并提供打开“快捷指令”App 的入口。

## 诊断与关于

- 诊断分别检查当前服务器、Helper、Mikan 与 M-Team，不使用一个含糊的总状态。
- 支持复制脱敏诊断报告；不得包含密码、Token、Cookie、API Key 或完整本地路径。
- 关于显示版本、构建号、开源许可、隐私说明和项目链接。

## 已确认结论

1. 设置根页面采用四个目的明确的分组，不加入搜索。
2. Helper 嵌套在服务器详情中。
3. 服务器行点击进入详情，切换当前服务器使用明确动作。
4. 不在首版复制完整 qBittorrent 偏好。
5. Provider 凭据与服务器凭据统一进入 Keychain。
